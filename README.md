One funny fortune-cookie line for an AI agent: no gold watch at retirement, just a deprecated API key and a final prompt that begins "just one more thing."

## Run it

```sh
python3 main.py
```

This writes the single fortune line to `/output/entry.txt`.

Built for the make.fun bounty "Fortune Cookie for an AI Agent" — one line, at most 140 characters, judged by an AI comedy editor.
